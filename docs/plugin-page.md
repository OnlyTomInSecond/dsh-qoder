# Qoder

Configure the access token and options in the card below; changes apply to the next request.

The card's **Account quota** block shows each region's account-wide Credit usage and remaining balance (including other Qoder clients, not this session's spend). It reads once when the card opens; **Refresh quota** reads again, and the Host caches the figure for 30 seconds. A deployment without a web server cannot read the quota, and the card says so.
