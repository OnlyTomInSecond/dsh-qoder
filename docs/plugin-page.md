# Qoder

Configure the access token and options in the card below; changes apply to the next request.

The card's **Account quota** block shows each region's account-wide Credit usage and remaining balance (including other Qoder clients, not this session's spend). It reads once when the page view opens; **Refresh quota** reads again, and the Host caches the figure for 30 seconds. The leading line is whichever bucket the account has — a personal plan reports a personal quota, an enterprise one reports only an organization resource package — and it is named, because the number means something different per bucket. Only the owner can read it, and a deployment without a web server cannot read the quota; the card says so.
